# Jetlet shorts: posting plan

One clip a day. Post the same file to YouTube Shorts, TikTok and Instagram Reels.
Links in Shorts and TikTok captions aren't clickable, so every description says to
search "Jetlet". Put the Play link in your profile bio:
https://play.google.com/store/apps/details?id=com.eternalsky.jetlet

On TikTok and Reels there is no separate title: post the title line, then the
description, as one caption.

## Tips

- **Post around the same time each day**, in the evening of your target region.
- **TikTok sound:** TikTok favours trending sounds. You can keep the game music
  or swap in a trending sound in the TikTok editor (keep it quiet under gameplay).
- **Reply to every comment** in the first hour; it boosts reach on all three apps.
- **After a week**, check which clip got the most views and make more like it.
